🔍 Apa itu MicroTools? ▼
Platform berisi 3 aplikasi produktivitas: To-Do List, Catatan Harian, dan Kalkulator Finansial. Dibangun dengan vanilla JavaScript dan Supabase (auth + database). Bukti bahwa saya bisa membangun aplikasi interaktif dari nol.
🎯 Kenapa vanilla JS dulu? ▼
Saya percaya fondasi kuat itu penting. Sebelum lompat ke React, saya kuasai dulu DOM manipulation, event handling, dan state management dengan vanilla JS. Ini bikin saya lebih siap memahami apa yang dilakukan React di balik layar.
